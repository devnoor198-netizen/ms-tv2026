## 🎯 نظرة عامة

**MS TV** هي منصة IPTV احترافية تتيح لك:
- 🎬 عرض قنوات البث المباشر
- 🎛️ إدارة القنوات من لوحة تحكم مدمجة
- 📱 تصميم متجاوب يعمل على كل الأجهزة
- 🔒 نظام حماية بكلمة مرور
- 🎨 تصميم Cyberpunk عصري

**التقنيات:** HTML5 • CSS3 • Vanilla JavaScript — بدون أي مكتبات خارجية ثقيلة.
